# Order Management System WordPress Plugin

## Overview
This WordPress plugin is designed to facilitate the synchronization of order data between a mobile application and a WordPress backend. It allows users to manage orders efficiently, ensuring that all order details are captured and stored securely.

## Features
- **Order Synchronization**: Sync orders placed through the mobile app with the WordPress backend.
- **API Endpoints**: Provides RESTful API endpoints for handling order data.
- **Settings Management**: Allows configuration of plugin settings through the WordPress admin interface.
- **Reporting**: Generate reports on orders placed, including totals and donation amounts.

## Installation
1. Download the plugin files.
2. Upload the `wp-plugin` directory to the `/wp-content/plugins/` directory of your WordPress installation.
3. Activate the plugin through the 'Plugins' menu in WordPress.

## Usage
- After activation, navigate to the plugin settings to configure any necessary options.
- The plugin will automatically handle incoming order data from the mobile application.
