# Documentation

Two documents, both self-contained HTML with their screenshots embedded, so
either one opens in a browser with no server and nothing to install.

| File | For | Covers |
|------|-----|--------|
| `sub-sale-playbook.html` | Adults running a sale | Opening a season, kid and driver sign-up, taking an order, the customer's receipt, driving on a sale day |
| `how-to-sell-a-sub.html` | The kids | Signing up with friends, then selling at the door. Also carries the shot list for the training video |

`screenshots/` holds the same images as separate files, named by the IDs the two
documents use (SS-01, SS-02 …), for anyone cutting the video or writing
something new. `screenshots/MANIFEST.txt` lists each one.

## Keeping them current

The screenshot IDs are the join between the documents, the files and the video
shot list, so an ID means one screen for good. When a screen changes materially,
replace that image rather than adding another ID.

The playbook's appendix tracks which IDs still need capturing. Outstanding at
the time of writing: the receipt and conversation screens (SS-36 to SS-39) and
an order in edit mode (SS-44), which needs taking against 3.66.1 or later
because earlier builds show two bugs that have since been fixed.
